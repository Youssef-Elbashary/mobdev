### A component is a function that returns UI

```tsx title="Greeting.tsx"
function Greeting() {

<Greeting />
```

### A `TextInput` is controlled by state

```tsx title="App.tsx"
const [name, setName] = useState('');

<TextInput value={name} onChangeText={setName} placeholder="Your name" />

```

### One more idea: function props

A child can’t change the parent’s state — but the parent can **give it a function** to call.

```tsx title="App.tsx → ContactCard.tsx"
// parent (App): owns the state, passes a function down
<ContactCard name={c.name} favourite={favs.includes(c.id)} onToggle={() => toggle(c.id)} />

// child (ContactCard): calls it when tapped
<Pressable onPress={onToggle}><Text>{favourite ? '★' : '☆'}</Text></Pressable>
```

<Cards cols={3} items={[
  { title: 'Data goes down', text: 'Props carry values from parent to child.' },
  { title: 'Events go up', text: 'Function props let the child tell the parent “I was tapped”.' },
  { title: 'State lives on top', text: 'Keep state in the closest parent that needs it.' },
]} />

## Optional challenge: take it into Expo

The exercises above run in this page so you can practise quickly. Now use the same ideas in a real Expo project: a four-screen **Movies watchlist**. This section comes from the longer practical version of Lab 02 and is the best next step if you finish early.

### File-based routing

Expo Router turns files inside `app/` into screens. Square brackets make a dynamic route, so `movie/[id].tsx` can open `/movie/1`, `/movie/2`, and so on.

<FileTree title="movies-app" lines={[
  'app/',
  '  _layout.tsx # Stack + MoviesProvider',
  '  (tabs)/',
  '    _layout.tsx # Movies · Watchlist · Add',
  '    index.tsx # all movies *',
  '    watchlist.tsx # saved movies *',
  '    add.tsx # controlled form *',
  '  movie/',
  '    [id].tsx # movie details *',
  'components/',
  '  MovieCard.tsx # receives one movie as props',
  'context/',
  '  movies.tsx # shared movies + watchlist state',
]} />

<Cards cols={3} items={[
  { icon: 'layers', title: 'Stack', code: '<Stack />', text: 'Details slide on top and get a Back button.' },
  { icon: 'grid', title: 'Tabs', code: '<Tabs />', text: 'Switch between Movies, Watchlist and Add.' },
  { icon: 'link', title: 'Navigate', code: "router.push('/add')", text: 'Or wrap a card with `<Link href>`.' },
]} />

```tsx title="app/movie/[id].tsx"
const { id } = useLocalSearchParams<{ id: string }>();
const movie = movies.find((item) => item.id === id);
```

> [!WARNING]
> Route parameters are strings. Convert `id` first if your data uses numeric IDs.

### Build the four screens

1. **Movies:** render the data with `FlatList`, extract a reusable `MovieCard`, and filter by title.
2. **Details:** read the route `id`, show the movie, and toggle it in the watchlist.
3. **Watchlist:** reuse `MovieCard`; include a count and a friendly empty state.
4. **Add movie:** use controlled inputs, validate the title and year, then add the new movie to shared state.

The watchlist changes on the Details screen but appears on another tab, so keep it in a Context provider above both screens.
