troubleshooting:
  - problem: '"Missing script: reset-project"'
    cause: The terminal is not inside the project folder.
    solution: Go into the project folder first, then run it again.
    commands: ['cd my-first-app', 'npm run reset-project']
  - problem: Expo Go keeps loading / can't connect
    cause: Your phone and laptop are on different networks, or the campus Wi-Fi blocks them from reaching each other.
    solution: Stop the server with Ctrl + C and start it in tunnel mode.
    commands: ['npx expo start --tunnel']
  - problem: '"Author identity unknown — Please tell me who you are"'
    cause: Git doesn't know your name and email yet.
    solution: Do Task 4.3, then commit again.
    commands: ['git config --global user.name "Your Name"', 'git config --global user.email "you@bue.edu.eg"']
  - problem: '"Support for password authentication was removed"'
    cause: You typed your GitHub password. The terminal only accepts a token.
    solution: 'Push again and paste your **token** (Task 4.5) where it asks for the password.'
    commands: ['git push -u origin main']
  - problem: 403 / "Permission denied" on push (Windows)
    cause: Windows saved a different GitHub account.
    solution: 'Open **Credential Manager → Windows Credentials**, remove `git:https://github.com`, then push again and sign in with your token.'
  - problem: '"error: remote origin already exists"'
    solution: Point origin at the correct URL instead of adding it again.
    commands: ['git remote set-url origin https://github.com/your-username/my-first-app.git']
  - problem: '"error: src refspec main does not match any"'
    cause: There is no commit yet, or the branch isn't called main.
    solution: Commit first, then rename the branch and push.
    commands: ['git add .', 'git commit -m "First commit"', 'git branch -M main', 'git push -u origin main']

<Task n="3.6" title="Build a tiny UI — the 5 basics" time="10 min">

<AppPhone markers />

1. **`View`**: the box that holds everything (like a `div`)
2. **`Image`**: a picture from a file or a URL (like `img`)
3. **`Text`**: **all** text must be inside `Text` (like `p`)
4. **`TextInput`**: a box the user can type in (like `input`)
5. **`Pressable`**: anything the user can tap (like `button`)

Open `app/index.tsx`, delete everything and paste:

```tsx title="app/index.tsx" {2}
import { useState } from 'react';
import { View, Text, Image, TextInput, Pressable, StyleSheet } from 'react-native';

export default function Index() {
  const [name, setName] = useState('');   // what the user typed
  const [count, setCount] = useState(0);   // how many taps

  return (
    <View style={styles.screen}>
      <Image source={{ uri: 'https://reactnative.dev/img/tiny_logo.png' }} style={styles.logo} />
      <Text style={styles.title}>Hello, {name || 'Mobile Dev'} 👋</Text>
      <TextInput style={styles.input} placeholder="Type your name…" value={name} onChangeText={setName} />
      <Pressable style={styles.button} onPress={() => setCount(count + 1)}>
        <Text style={styles.buttonText}>Tapped {count} times</Text>
      </Pressable>
    </View>
  );
}

const styles = StyleSheet.create({
  screen: { flex: 1, alignItems: 'center', justifyContent: 'center', gap: 16, padding: 24 },
  logo: { width: 64, height: 64 },
  title: { fontSize: 24, fontWeight: '700' },
  input: { width: '100%', borderWidth: 1, borderColor: '#ccc', borderRadius: 10, padding: 12 },
  button: { backgroundColor: '#111', paddingVertical: 12, paddingHorizontal: 20, borderRadius: 10 },
  buttonText: { color: '#fff', fontWeight: '600' },
});
```

<Task n="4.5" title="Create a token" time="6 min">

GitHub does **not** accept your password in the terminal. It wants a **token**: a long, secret password made just for Git.

<ClickPath steps={['Profile picture', 'Settings', 'Developer settings', 'Personal access tokens', 'Tokens (classic)', 'Generate new token', 'Generate new token (classic)']} />

<GhToken />

1. **Note**: a name so you remember what it's for, e.g. `mobile-dev-laptop`
2. **Expiration**: **90 days** lasts the whole semester
3. **repo**: tick it. This lets the token push to your repositories
4. **Generate token**

<GhToken done />

1. GitHub shows the token **only once**
2. **Copy it now** and keep it somewhere safe. If you lose it, just make a new one

> [!WARNING]
> A token works like your password. Never share it, never paste it in your code, never commit it.

</Task>
